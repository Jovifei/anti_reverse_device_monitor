# 验收标准

## 1. 一期功能验收

### 1.1 数据导入

- 支持导入 Excel；
- 必须识别设备 SN；
- 必须支持多设备；
- 重复导入幂等；
- 错误行进入导入报告；
- 时间统一转换；
- 空值不等于 0；
- 导入批次可追踪。

### 1.2 设备总览

- 最近 7 天活跃设备可见；
- 超过 7 天无数据设备默认隐藏；
- 最近 7 天上过线但当前离线的设备仍显示；
- SN 搜索可用；
- 在线、离线筛选可用；
- 点击进入设备详情。

### 1.3 CT 页面

- CT 本体在线状态正确；
- 离线持续时间正确；
- A/B/C 三相负值触发严重告警；
- 告警区间开始、恢复、最低值正确；
- 功率总览可选曲线；
- 1/3/7 天切换；
- 滚轮缩放；
- 拖动平移；
- 双击/按钮复位；
- 电压和频率并排；
- 今日发电量、累计发电量、发电时长正确。

### 1.4 微逆页面

每台 1～8：

- 在线状态正确；
- 工作状态正确；
- 当前是否发电正确；
- 在线亮色、离线灰色；
- PV1、PV2、总功率正确；
- 今日、累计发电量正确；
- 发电时长正确；
- 温度曲线正确；
- 丢包率正确；
- 故障名称正确；
- 状态和故障变化时间正确；
- 缺失的 SN 和版本显示 `—`，不得伪造。

### 1.5 数据保留

- 原始遥测只保留配置天数；
- 默认 7 天；
- 清理不会删除设备元数据和最新状态；
- 清理任务有日志；
- 可在测试环境模拟验证。

## 2. 数据正确性验收

抽取至少以下样例人工对比：

1. 一台正常设备；
2. 一台当前离线设备；
3. 一台发生逆流设备；
4. 一台微逆未配对；
5. 一台微逆在线；
6. 一台微逆离线；
7. 一条非零故障码；
8. 一条故障恢复；
9. 一段跨小时曲线；
10. 一段跨天曲线。

## 3. 性能验收

- 设备总览不读取完整历史表；
- 单设备默认只查询所选时间范围；
- 设备列表分页；
- 遥测查询有索引；
- 大数据量查询使用聚合或降采样；
- 页面不存在一次返回所有公司设备 7 天原始数据的接口。

## 4. 安全验收

- `.env.local` 未提交；
- 浏览器中没有数据库密码；
- 源数据库账号只读；
- 不存在写入源数据库代码；
- 不存在 MQTT 发布代码；
- 日志不打印密码；
- API 对 SN 和时间范围做校验；
- SQL 不拼接用户输入；
- 生产部署启用 HTTPS。

## 5. 测试要求

### 单元测试

- 状态枚举；
- 故障位解码；
- 逆流告警区间；
- 离线持续时长；
- 数据保留；
- Excel 字段映射；
- SN 规范化。

### 集成测试

- Excel 导入到 SQLite；
- 查询最新状态；
- 查询历史曲线；
- 重复导入；
- 清理任务；
- SQLite 到 PostgreSQL 迁移模拟。

### 端到端测试

- 总览搜索；
- SN 切换；
- 功率图选择；
- 时间范围切换；
- 图表缩放；
- 微逆详情；
- 故障记录；
- 离线设备显示。
