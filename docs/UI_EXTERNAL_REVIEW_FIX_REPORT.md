# 外部 UI 审阅修复报告

基线：`codex/phase2-ui-acceptance` @ `c7866ad`。本轮不连接公司数据库、不进入 PostgreSQL、不推送、不合并。

## P0/P1 问题与证据

| 问题 | 修复证据 |
| --- | --- |
| 在线 CT 因固定时间过期 | `scripts/seed-demo.ts` 以单一 seedNow 生成最新上报和心跳；在线/逆流最新样本相对执行时间不超过 2 分钟，离线样本保留在 7 天窗口内。E2E 汇总断言通过。 |
| 在线/离线/严重逆流计数不稳定 | Demo 总览 E2E 验证在线 2、离线 1、严重逆流 1。 |
| 在线发电状态与 0 W 矛盾 | `isGenerating` 同时检查 `online_state`、`work_state` 和实时总功率；在线正功率、待机 0 W、离线不发电均由单元/E2E 覆盖。 |
| 逆流数据总量矛盾 | 当前逆流样本固定为家庭负载 950 W、微逆 1370 W、电网 -420 W，A=-160 W、B=0 W、C=-260 W；E2E 验证首屏告警和数值。 |
| CT 顶部信息层级和数据来源面板 | 顶部改为标题/SN/只读 `数据来源：Demo SQLite`，随后统一逆流安全区、CT 状态、KPI、质量和功率总览；独立大面板已移除。 |
| 重复防逆流区域 | 逆流标题、当前总状态、A/B/C、告警摘要和 7 天记录收敛到一个 `reverse-safety-panel`；逆流设备首屏显示红色严重告警。 |
| 三相卡片和历史曲线 | 负值卡整卡浅红、数值红色并显示“正在反送电网/查看 7 天曲线”；图表使用中性主线、红色负值点和红色 0 W 虚线，无负点时不生成空图例。 |
| 功率总览过载 | 默认三条核心曲线；CT/微逆相位曲线折叠到默认关闭的“更多曲线”，范围、Tooltip、缩放、拖动、slider 和复位保留。 |
| 微逆卡片重复和高度 | 每张卡只保留一套状态、功率/PV、能量、时长、温度、丢包率和故障；可点击指标直接打开历史，网格仍固定 8 台。 |
| 单位、开关和功率限制 | 统一显示 W、kWh、h、°C、%；1/0 映射开启/关闭，功率限制以 W 显示。单元和详情 E2E 通过。 |
| 状态持续时间 | telemetry connectivity 返回在线/离线 stateSince 与 current*Minutes；详情页在线不再显示“—”，并有边界单元测试。 |
| 离线 CT 最后已知语义 | 离线 CT 状态、功率、电压、频率和 Sub1G 增加最后已知说明及更新时间，页面采用灰色语义。 |
| 移动端布局和弹窗 | 390px 状态/KPI/质量使用两列、三相紧凑、微逆单列；弹窗使用 fixed/inset 全屏、50vh 图表、ESC/遮罩/按钮关闭和 body 滚动锁定。移动 E2E 通过。 |
