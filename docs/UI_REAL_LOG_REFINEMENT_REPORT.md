# UI 真实日志参考改造报告

## 目标

将真实日志预览中可复用的运行监控层级转化为基于 SQLite Demo 数据、服务端查询和动态路由的正式页面交互；不复制真实日志内容，不读取或提交 `log/` 与本地预览文件。

## 本轮页面改进

- CT 页同时呈现平台状态、最后上报、领域字典转换后的 CT 状态、电网质量和只读数据来源标签。
- 当前逆流使用高优先级严重告警横幅；A/B/C 相位卡片可点击查看 7 天历史，负功率点与零基准线清晰可见。
- 功率总览默认只勾选家庭负载、电网功率和微逆发电总功率，其余曲线保持可选。
- 固定 8 张微逆卡片分别呈现在线状态、功率、PV1、PV2、今日发电量、累计发电量、今日发电时长、内部温度、丢包率和中文故障名称；缺失值显示“—”。
- PV1、PV2、总功率、温度和今日发电量可打开独立历史弹窗；今日发电量按自然日断开连线。
- E2E 覆盖卡片的“今日发电时长”、带空格的故障名称、旧无空格故障文案缺失，以及 `undefined`、`null`、`NaN` 缺失。

## 质量边界

- 数据源标签为只读显示，不包含账号、地址、查询条件或记录明细。
- 图表仍使用服务端限定的 7 天数据窗口；浏览器不直接连接数据库。
- 页面不新增设备控制、MQTT、OTA、配对或解绑能力。
