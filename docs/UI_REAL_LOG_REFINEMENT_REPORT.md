# UI 真实日志参考改造报告

## 目标

将真实日志预览中可复用的运行监控层级，转化为基于 SQLite 演示数据、服务端查询和动态路由的正式页面交互；不复制真实日志内容。

## 完成项

- CT 顶部同时呈现平台状态、最后上报、领域字典转换后的 CT 状态、电网质量和只读数据来源标签。
- 当前逆流使用高优先级严重告警横幅；A/B/C 相位卡片可点击查看 7 天历史，负功率点及零基准线清晰可见。
- 功率总览默认只勾选家庭负载、电网功率和微逆发电总功率，其余曲线保持可选。
- 固定 8 张微逆卡片分别呈现在线状态、功率、PV1/PV2、温度、丢包率、电量和中文故障名称。
- PV1、PV2、总功率、温度、今日发电量可打开独立历史弹窗；今日发电量按自然日断开连线。
- 新增 Playwright 交互覆盖和截图脚本，覆盖桌面、移动端、逆流、离线、未配对和故障场景。

## 质量边界

- 数据源标签为只读显示，不包含账号、地址、查询条件或记录明细。
- 图表仍使用服务端限定的 7 天数据窗口；浏览器不直接连接数据库。
- 页面不新增任何设备控制、MQTT、OTA、配对或解绑能力。
