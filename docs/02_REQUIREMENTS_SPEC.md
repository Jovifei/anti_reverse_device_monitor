# 需求规格说明

## 1. 用户角色

### 1.1 工程研发人员

需要查看原始运行数据、曲线、状态码、故障变化和通信质量。

### 1.2 售后与运维人员

需要通过 SN 快速定位设备，判断设备离线、微逆离线、逆流告警和具体故障。

### 1.3 产品与管理人员

需要在总览页观察在线设备、近期活跃设备、严重告警和发电情况。

## 2. 数据范围

- 原始连续数据默认保留最近 7 天；
- 页面支持最近 24 小时、3 天、7 天；
- 设备超过 7 天未上线且无数据时，默认不进入总览；
- 设备最近 7 天上过线，但当前离线时，必须继续显示并标记离线；
- 微逆状态与 CT 本体状态必须分开判断。

## 3. 设备总览需求

总览页必须支持：

- SN 搜索；
- 在线、离线筛选；
- 最近 7 天活跃设备列表；
- CT 本体在线状态；
- 最后上报时间；
- 当前是否发生三相逆流；
- 最近 7 天严重逆流告警数量；
- 有数据或已配对的微逆数量；
- 当前在线微逆数量；
- 点击进入单设备运行面板。

## 4. CT 设备运行面板

### 4.1 SN 切换

用户可以输入完整 SN 或可识别的末尾编号，加载另一台设备。

当前离线原型只有 `GC2001000000252`，正式系统应调用：

```text
GET /api/devices/{sn}
GET /api/devices/{sn}/latest
GET /api/devices/{sn}/telemetry
```

### 4.2 CT 本体状态

展示：

- 本体在线、离线；
- 当前离线持续时间；
- 运行状态 `state`；
- 限流状态 `limit_state`；
- Sub1G 状态 `sub1g_state`；
- 工作模式 `work_mode`；
- 最后上报时间。

### 4.3 防逆流安全状态

A、B、C 三相分别读取：

- `active_power_ct1`
- `active_power_ct2`
- `active_power_ct3`

业务规则：

```text
任一相功率 < 0 W
→ 功率向电网反送
→ 严重告警
```

页面必须展示：

- 当前三相功率；
- 当前是否逆流；
- 告警开始时间；
- 恢复时间；
- 持续时长；
- 该次最低功率；
- 最近 7 天告警记录。

### 4.4 功率总览

核心主图必须支持选择：

- 家庭负载功率；
- 电网功率；
- 微逆发电总功率；
- A/B/C 三相 CT 有功功率；
- A/B/C 三相微逆当前功率。

交互要求：

- 1 天、3 天、7 天切换；
- 鼠标滚轮缩放；
- 拖动平移；
- 双击或按钮复位；
- Tooltip 显示时间和值；
- 负值点标红。

### 4.5 能源数据

顶部保留：

- 今日发电量；
- 今日发电时长；
- 累计发电量。

不重复展示：

- 今日用电估算；
- 7 日发电与用电汇总；
- 页面下方重复的相同能源 KPI。

家庭总用电如果公司数据源没有累计量，可暂不作为核心 KPI。

### 4.6 电网质量

电网电压和频率并排展示：

- `grid_voltage`
- `grid_frequency`

支持曲线、最新值和异常阈值。

## 5. 微型逆变器 1～8

### 5.1 卡片状态

每台微逆独立卡片：

- 在线：亮色；
- 离线：灰色；
- 未配对或无数据：虚线或中性状态；
- CT 在线不代表微逆在线；
- 夜间微逆离线不应自动判断为 CT 故障。

### 5.2 微逆详情标题

展示顺序：

```text
微型逆变器 N：微逆 SN
软件版本 · 硬件版本 · Sub1G 版本
```

当前数据未提供的值显示 `—`，禁止编造。

### 5.3 微逆状态

展示：

- `online_state`
  - 0 未配对
  - 1 离线
  - 2 在线
- `work_state`
  - 0 待机
  - 1 发电
  - 2 断电
  - 3 限流发电
- 当前是否正在发电；
- 当前状态持续时长；
- 在线、离线变化记录。

### 5.4 微逆功率

第一行：

- 发电总功率；
- PV1 功率；
- PV2 功率。

主曲线支持缩放和平移。

### 5.5 微逆能源

第二行：

- 今日发电量；
- 累计发电量；
- 今日发电时长。

### 5.6 微逆其他指标

- 最近丢包率；
- 内部温度大图；
- 所在相重点显示；
- 接入点小字显示；
- 防逆流开关；
- 发电开关；
- 功率限制；
- 微逆 SN；
- 软件版本；
- 硬件版本；
- Sub1G 版本；
- 产品个性化属性。

### 5.7 故障展示

`fault_param` 是 32 位位掩码。

页面显示：

- 最新十六进制故障码；
- 直接解码后的故障名称；
- 不在用户界面强调 bit 编号；
- 故障出现、变化、恢复时间；
- 历史故障记录。

## 6. 非功能需求

- 页面适配桌面和常规笔记本；
- 大图优先保证可读性；
- 设备列表和历史数据必须分页；
- 数据查询必须有超时；
- 所有公司数据库访问都在服务端；
- 源数据库账号必须只读；
- 环境变量不得提交 Git；
- 页面不得暴露数据库地址和密码；
- 原始遥测保留 7 天后自动清理；
- 导入和同步必须支持断点续传和去重。
