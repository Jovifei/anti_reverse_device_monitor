# 真实日志预览参考审计

## 范围

本次仅在本机浏览器中查看离线预览 HTML，用于核对运行监控信息架构和视觉层级。真实日志、导出的预览文件、原始设备标识和数据行均未复制到工程文件、测试、截图报告或 Git 提交。

## 参考到的有效设计信号

- 多设备入口采用紧凑的设备切换结构，页面主体聚焦单台设备当前运行状态。
- 顶部将功率、日电量、累计电量、运行时长、电网质量和设备状态组合为可快速扫读的运行摘要。
- A/B/C 三相功率作为独立可辨识单元呈现，逆流状态需要具有高于普通指标的视觉优先级。
- 微型逆变器以逐台卡片呈现，在线、离线、未配对和无数据不能混为同一种状态。
- 趋势图应服务于异常追溯，而不是仅展示静态数字。

## 未复制的部分

- 未复制任何真实 SN、时间戳、功率、电量、版本、故障码或原始日志记录。
- 未复制预览页面中的静态数据、HTML、脚本、样式或设备切换实现。
- 参考页面未提供相位历史弹窗、单指标历史弹窗和生产数据源切换能力；这些交互在正式页面中基于现有服务端查询独立实现。

## 正式页面落地

- CT 页面采用数据库服务和动态路由，顶部新增运行状态、电网质量和只读数据来源标签。
- 逆流采用醒目横幅、相位卡片、负功率零基准线和最近 7 天告警记录组合呈现。
- 微逆卡片固定 1 至 8 通道，支持 PV1、PV2、总功率、温度和今日电量的按需历史查看。
- 所有缺失值继续使用 `—`，真实数据源信息不暴露至浏览器。
