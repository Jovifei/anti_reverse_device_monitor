## 首页默认视图改为「近7天活跃设备」（18:20-18:35）
- **需求**：用户要求点开首页默认只展示近 7 天内有在线活跃过的设备；逆流/离线/僵尸设备改为需主动跳转的分类。
- **根因（语义 bug）**：`app/devices/page.tsx` FILTERS 首项标签写「全部活跃设备」，但 service 层 `parsed.status === 'all'` 走的是末尾 `return true` → 实际返回全量 372 台。标签与行为对不上，360 台僵尸设备混进默认视图。
- **设计决策**：新增 `active` 状态作为默认值，`all` 保留为真·全量。不破坏已有 `?status=all` 深链；默认 active 时 URL 省略 status 参数，`/devices` 直接即目标视图。
- **改动（团队 software-fleet-default-view / software-engineer agent 实现）**：
  - `src/domain/validation.ts`：status 枚举加 `'active'`（首位），`.default('all')` → `.default('active')`
  - `src/services/device-service.ts`：filter 加一行 `if (parsed.status === 'active') return item.classifyStatus === 'active'`；**summary 一行未动**（activeTotal/staleOfflineCount 仍基于 activeItems/mergedItems）
  - `app/devices/page.tsx`：新增 `DEFAULT_STATUS='active'` 常量；FILTERS 首项改 `{active,'近7天活跃设备'}`、末尾加 `{all,'全部设备'}`；`fleetListHref`/`paginationHref`/搜索表单隐藏域/兜底值 4 处 `!== 'all'` → `!== DEFAULT_STATUS`；空态文案改为 `q ? '没有匹配「q」的设备。' : '当前筛选条件下没有设备。'`
  - `app/page.tsx` 未改（`redirect('/devices')` 无参数即走 default active）
- **隐藏域是关键补漏**：工程师主动发现 spec 遗漏——搜索表单隐藏域若只改 href 函数不改它，用户在「全部设备」下搜 SN 会因 status 参数被省略、服务端兜底 active 而静默丢失筛选条件。已按同一规则修正。
- **测试**：新增 4 个用例（validation 2 个测 default=active；classify 2 个测「默认只返 active / status=all 返全量」+「显式 active 与默认等价」，并断言两者 summary.registryTotal 与 staleOfflineCount 相等以锁死"列表过滤不影响 summary 口径"）；改 2 个既有用例（原依赖"默认返回全量"前提，改为显式 `{status:'all'}`）。vitest 161→165，零回归。
- **数据佐证**：config/devices.json 实测 registryTotal=372、online===true=12、非 online=360，与用户截图完全对应。
- **⚠️ 遗留口径不一致（需单独起 change）**：KPI 卡片 `summary.activeTotal` 取自 Mongo `activeItems`，而 `status='active'` 列表过滤依据 `classifyStatus`（Mongo 近7天上报 **OR** IoT 注册表 online===true）。当前 SOURCE_DB_ENABLED=false → activeItems 空集 → 卡片显示 0、列表显示 12 台，**当下已在打架**。需产品先定「活跃」以哪个数据源为准。
- **环境坑（复现率高，务必记住）**：① 本环境 safe-delete shim 会拦截 Next.js 构建过程中的 `fs.unlink`（报 `[safe-delete] 操作失败 ... ETIMEDOUT`），导致 build 中断——需先用 PowerShell `Remove-Item -Recurse -Force .next` 清干净再构建；② Git Bash PATH 间歇性失效，报 `env: 'bash': No such file or directory` / `command not found` + exit 127，**直接切 PowerShell 工具即可，不要怀疑命令本身**；③ vitest 偶发 V8 原生崩溃 exit 134（裸地址栈帧、无测试失败信息），加 `NODE_OPTIONS=--max-old-space-size=4096` 后即全绿，是内存压力不是测试问题。
